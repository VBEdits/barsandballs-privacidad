# Política de privacidad — Bars & Balls

Esta página existe porque Google Play exige que la política de privacidad de
una aplicación esté publicada en una **URL pública**.

Se publica en: https://vbedits.github.io/barsandballs-privacidad/

El texto se mantiene en el repositorio del juego (`docs/privacidad.md`) y se
copia aquí al publicarlo. Si cambia lo que el juego hace con los datos, se
actualiza allí primero: la política tiene que describir lo que el código hace
de verdad, no al revés.
